# Flappy Milena — сборка APK в облаке

Этот проект собирается в GitHub Actions; Android Studio на вашем компьютере не требуется.

## Как получить APK

1. Войдите на https://github.com/ и создайте новый репозиторий (например, `flappy-milena`).
2. В настройках создания репозитория выберите **Public** (для бесплатного и простого пути) и создайте его.
3. На странице репозитория нажмите **Add file → Upload files**.
4. Распакуйте ZIP на компьютере и загрузите ВСЁ содержимое папки `flappy_milena_cloud` (включая скрытую папку `.github`). Если веб-интерфейс не показывает `.github`, загрузите проект через веб-редактор или GitHub Desktop; не создавайте папку `github` без точки.
5. Нажмите **Commit changes**.
6. Откройте вкладку **Actions** в репозитории. Workflow `Build Flappy Milena APK` должен запуститься автоматически после коммита в ветку `main`.
7. Нажмите на завершённый запуск (зелёная галочка), прокрутите вниз до **Artifacts** и скачайте `FlappyMilena-APK`.
8. Распакуйте скачанный архив. Внутри будет `app-debug.apk`.
9. Передайте `app-debug.apk` на Galaxy A35, откройте файл и разрешите установку из этого источника, если Android спросит.

## Важно

- APK подписан debug-ключом автоматически и подходит для личной установки/тестирования, не для публикации в Google Play.
- Сборка требует интернет в GitHub Actions, чтобы загрузить Gradle/Android SDK.
- Не загружайте секреты, пароли или приватные ключи в репозиторий.
- Если сборка упадёт, откройте failed run и пришлите мне текст ошибки или скриншот — помогу исправить.
